# More Umapyoi Skills

### 概要
このMODは[Umapyoi](https://www.curseforge.com/minecraft/mc-mods/umapyoi)のアドオンMODです。<br>
新しく幾つかのスキルとそれらを習得することの出来るサポートカードを追加します。<br>

***
### 入手手段
「サポートカード(スキル)」<br>
 - 主にガチャで入手 
 - 一部のスキルはガチャで入手できず、クラフトでスキル本を入手することが出来ます

***
### 追加スキル概要 
「天馬(SR) / 天の覇者(SSR)」<br>
 - 消費アクションPt : 900 / 1400
 - 依存能力 : 賢さ
 - 一定時間の間、クリエイティブ飛行が出来る「天馬」のバフを得ます
 - 注意:連続使用時に浮遊状態が解除されます

「高跳び(SR) / 力強い跳躍(SSR)」<br>
- 消費アクションPt : 100 / 100
- 依存能力 : パワー
- 一瞬だけ「浮遊」の効果を得て上昇します

「トリッキー(SR) / 曲芸師(SSR)」<br>
- 消費アクションPt : 0 / 0
- 依存能力 : 根性
- このスキルを使用すると「スキルクールダウン」のデバフが30秒間付与されます
- 「スキルクールダウン」中はこのスキルを使用できません
- アクションポイントを即座に一定量回復します

「力戦奮闘(SSR)」<br>
- 消費アクションPt : 1900
- 依存能力 : 無し
- やる気を即座に2段階上昇させます

「俊足(SR)」<br>
- 消費アクションPt : 100
- 依存能力 : 無し
- 向いている方向に加速します

「威嚇(SR) / 超威嚇(SSR)」<br>
- 消費アクションPt : 400 / 900
- 依存能力 : 賢さ
- 周囲の生物を威嚇して攻撃力と移動速度を下げます

「不死鳥(SSR)」<br>
- 消費アクションPt : 0
- 依存能力 : スピード
- このスキルを使用すると「スキルクールダウン」のデバフが30秒間付与されます
- 「スキルクールダウン」中はこのスキルを使用できません
- HPを全回復します
- 空腹度を回復します
- 一瞬だけ無敵になります

「黒花のかく乱(SSR)」<br>
- 消費アクションPt : 900
- 依存能力 : 賢さ
- 周囲の生物に移動速度低下とウィザーの効果を付与し、自身に再生能力の効果を付与します

「余力十分(SR)」<br>
- パッシブスキル
- 依存能力 : スピード
- 自身のHPが最大の時、スピードに応じた移動速度上昇の効果を得ます

「華麗なテクニック(SSR)」<br>
- パッシブスキル
- 依存能力 : 賢さ
- アクションポイントの自然回復量が上昇します
- 賢さの能力が高い程より高い効果を得ます

「スマートな着地(SSR)」<br>
- パッシブスキル
- 依存能力 : 根性
- 受ける落下ダメージを制限します
- 根性の能力が高いほどより受ける落下ダメージの上限が減ります

「力強い一撃(SSR)」<br>
- パッシブスキル
- 依存能力 : パワー
- パワーに応じた量のダメージボーナスを得ます

「粘り強い脚力(SSR)」<br>
- パッシブスキル
- 依存能力 : スタミナ
- 「掛かり」状態で無いとき、空腹度が一定値から減らなくなります
- スタミナの能力が高いほどより空腹度の下限が増加します

「不滅の意思(Unique)」<br>
- パッシブスキル
- 依存能力 : 無し
- クラフトでスキル本を入手することでのみ習得可能
- このスキルは継承できません
- このスキルを持っているウマ娘魂は、死亡してもインベントリから落としません
